**서재앱 화면 설계서** (2026-09-23 시작)

화면마다 무엇이 있고, 무엇을 누르면 어떻게 되고, 상태별로 무엇을 보여줄지 정의한다. 색·글꼴·간격은 디자인 단계에서 정한다.

전제: 크롬 확장. 새 탭이 서재, 읽기 뷰어와 3D 서재가 확장 안 화면, 원문 페이지 위에는 선택 도구 모음. 자세한 전환 배경은 `서재앱_방향전환_260923.md`.

---

**0. 읽기 등급 (모든 읽기 화면의 전제)**

| 등급 | 상태 | 할 수 있는 것 |
|---|---|---|
| A | 본문을 깨끗하게 뽑음 | 텍스트 모드로 읽기, 하이라이트, 메모, 용어 설명, 요약 |
| B | 본문은 못 뽑고 화면은 남김 (스냅샷·PDF) | 원문 모드로 읽기, 책 전체 메모. 텍스트 하이라이트는 제한 |
| C | 원문을 못 가져옴 | 링크 + 내 메모 + 아카이브 주소 |

어떤 등급이든 책은 서재에 꽂히고 칸도 정해진다. 메타데이터·내 메모·아카이브 주소는 항상 남는다.

확장으로 바뀌면서 로그인·유료 기사가 C에서 A로 올라간다. 서버가 자동으로 가져오지는 못하므로 "내가 열어둔 상태에서 담기"가 전제다.

**1. 읽기 뷰어 (D-07)**

목적: 저장한 본문을 읽고 하이라이트·메모·용어 설명을 남긴다
진입: 새 탭에서 책 누르기, 칸 화면에서 책 누르기, 검색 결과, 칸 이어 읽기, 원문 페이지의 "서재에서 읽기"
나갈 때: 들어온 화면으로. 그 책이 꽂힌 자리가 보이는 상태로

영역 구성 (위에서 아래로)

| 영역 | 담기는 것 |
|---|---|
| 상단 바 | 뒤로, 책 제목(한 줄 줄임), 읽기 모드 토글(텍스트/원문), 더보기 |
| 진행 막대 | 읽은 위치를 얇은 선으로 (책갈피 리본) |
| 요약 블록 | 논문은 원문 초록 + 한 줄 요지, 기사는 3줄 요약. 접고 펼 수 있음 |
| 본문 | 문단, 소제목, 인용, 이미지와 캡션, 그림 자리표시 |
| 하단 바 | 메모 n개 보기, 원문 열기 |

요소별 동작

| 요소 | 누르면 | 기록되는 신호 |
|---|---|---|
| 뒤로 | 들어온 화면으로. 띠지가 벗겨진 상태 | 열람 기록 |
| 읽기 모드 토글 | 텍스트 ↔ 원문 | 원문 모드로 넘어간 횟수 |
| 더보기 | 다시 가져오기 / 칸 옮기기 / 보존 서고로 내리기 / 공유 | 다시 가져오기 누름 |
| 요약 접기 | 요약을 접고 본문부터 | 요약을 접는 빈도 |
| 요약 문장 | 그 문장의 원문 위치로 이동 | 근거 확인 횟수 |
| 요약 다시 생성 | 새 요약 생성 후 교체, 이전 버전 보관 | 요약 재생성 |
| 요약 직접 수정 | 편집 가능, 저장하면 "내가 고친 요약" 표시 | 요약 수정 |
| 문장 선택 | 작은 메뉴: 하이라이트 / 메모 / 용어 설명 | 선택 위치 |
| 하이라이트 | 밑줄 표시, 포스트잇 한 개 추가 | 하이라이트 생성 |
| 메모 | 입력창, 저장하면 하이라이트에 메모 표시 | 메모 생성 |
| 용어 설명 | 용어 설명 카드가 아래에서 올라옴 | 용어 설명 요청 |
| 그림 | 그림 설명 카드. 캡션이 있으면 캡션, 없으면 사서 설명 | 그림 설명 요청 |
| 메모 n개 보기 | 메모 모아보기 화면으로 | |
| 원문 열기 | 원문 링크를 새 탭으로 | 원문 이탈 |

상태별 화면

| 상태 | 보여주는 것 |
|---|---|
| 본문 준비 중 | 제목과 메타데이터는 보이고 본문 자리에 뼈대 표시 |
| A등급 | 기본 화면 |
| B등급 | 상단에 "읽기 품질이 낮아요" 띠와 다시 가져오기 버튼. 원문 모드 권유 |
| C등급 | 본문 자리에 안내와 원문 링크. 하이라이트는 막고 책 전체 메모만 |
| 수집 실패 | 실패 사유 한 줄과 다시 가져오기. 수집 실패 목록으로 가는 링크 |
| 오프라인 | 이미 받아둔 본문은 그대로, 용어 설명·상호대차는 잠김 표시 |
| 원문이 사라짐 | "원본은 사라졌고 내 서재에만 남아 있어요" 표시 |

보여줄 데이터
제목, 저자, 매체·출처, 발행일, 담은 날짜, 유형, 분량, 읽은 위치, 요약, 요약 버전, 본문, 이미지와 캡션, 하이라이트 목록, 메모 목록, 용어 설명 목록, 읽기 등급, 원본 링크, 아카이브 주소

규칙
- 읽은 것으로 치는 기준: 본문에서 20% 이상 내려가거나 30초 이상 머물면 띠지가 벗겨진다. 실수로 열었다 닫은 것은 읽은 것이 아니다
- 읽던 위치는 자동 저장하고, 다시 열면 그 자리에서 시작한다. 상단에 "이어서 읽기 / 처음부터"를 한 번 보여준다
- 읽는 중에는 사서가 말을 걸지 않는다. 질문 카드는 새 탭에 쌓인다
- 하이라이트는 저장한 본문 텍스트 기준이라 다시 가져오기를 하면 위치가 어긋날 수 있다. 어긋난 하이라이트는 지우지 않고 "위치를 찾지 못했어요" 표시로 남긴다
- 용어 설명과 그림 설명은 눌렀을 때만 만들고, 한 번 만든 것은 저장해 다시 쓴다

**2. 원문 페이지 위 도구 모음 (확장)**

목적: 웹을 보다가 그 자리에서 하이라이트·메모·용어 설명을 남긴다

- 문장을 선택하면 선택 영역 근처에 작은 메뉴가 뜬다: 하이라이트 / 메모 / 용어 설명 / 서재에서 읽기
- 이 페이지가 이미 서재에 있으면 기존 하이라이트를 페이지 위에 복원해 보여준다
- 담기지 않은 페이지에서 하이라이트하면 먼저 담고 하이라이트를 붙인다
- 확장 아이콘에는 이 페이지의 상태를 표시한다 (서재에 있음 / 없음 / 수집 중)

위치를 기억하는 방법
- 선택한 문장 그대로, 앞뒤 30자, 몇 번째 문단인지를 함께 저장한다
- 다시 열 때 문장을 찾아 표시한다. 구조가 바뀌어도 문장이 그대로면 찾아진다
- 같은 문장을 저장본에서도 찾아 위치를 계산해둔다. 그래서 원문에서 그은 하이라이트가 뷰어·메모 모아보기·책등 포스트잇에 모두 반영된다
- 찾지 못하면 지우지 않고 "위치를 찾지 못했어요"로 남긴다

제약
- PDF는 크롬 기본 뷰어 위에서는 어렵다. 우리 뷰어로 열면 된다
- 인터넷이 끊기면 확장 저장소에 넣어두고 연결되면 올린다
- 폰(PWA)에서는 원문 위 하이라이트가 안 되고 저장본에서만 가능하다
